## py.func.lambda

# 40 分钟教学讲义：`py.func.lambda`（Python 匿名函数）

## 一句话直觉

**当你只想把“一小段计算逻辑”当作参数塞进另一个函数（例如 `map`、`filter`、`sorted` 的 `key`）时，`lambda`（匿名函数）能让你不用 `def` 就把它就地写出来。**

---

## 第 1 节：什么是 lambda？——一行的匿名函数

`lambda` 是 Python 的关键字，用来创建**匿名函数**（anonymous function），也叫 lambda 表达式（lambda expression）。语法只有一种形式：

```
lambda 参数列表: 表达式
```

- 只能有**一个表达式**（expression），它的求值结果就是返回值。
- 没有 `return`，没有语句（statement），不能写多行逻辑。
- 结果是一个**函数对象**（function object），可以直接调用，也可以作为参数传递。

```python
# 定义一个普通函数
add = lambda x, y: x + y
print(add(2, 3))  # 5

# 等价于
def add_def(x, y):
    return x + y
```

**关键结论**：`lambda` 不是“更快的函数”，它只是 `def` 的表达式版本，专门用于**就地嵌入**。如果只是给函数起个名字，请用 `def`（PEP 8 明确建议）。

---

## 第 2 节：lambda 的真正价值——嵌入到表达式中

`lambda` 的唯一优势是：它本身是一个**表达式**，所以可以出现在 `def` 语句无法出现的地方——比如函数调用的参数里。

```python
nums = [1, -2, 3, -4, 5]

# 用 key 指定排序依据：按绝对值排序
sorted_nums = sorted(nums, key=lambda x: abs(x))
print(sorted_nums)  # [1, -2, 3, -4, 5]

# 用 map 做批量变换：每个元素加 10
added = list(map(lambda x: x + 10, nums))
print(added)  # [11, 8, 13, 6, 15]

# 用 filter 筛选正数
positives = list(filter(lambda x: x > 0, nums))
print(positives)  # [1, 3, 5]
```

**关键结论**：`lambda` 出现频率最高的三个场景是 `sorted(..., key=...)`、`map`、`filter`。

---

## 第 3 节：闭包与捕获——lambda 会记住外层变量

lambda 作为函数对象，会**捕获（capture）**定义它时所在作用域的变量，这叫**闭包**（closure）。但要注意：它捕获的是**变量本身**，而不是变量的值。

```python
def make_multiplier(n):
    # lambda 捕获了外层参数 n
    return lambda x: x * n

times3 = make_multiplier(3)
print(times3(10))  # 30
```

下面的例子暴露了“捕获变量而非值”的坑：

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)

print([f() for f in funcs])  # [2, 2, 2] 而不是 [0, 1, 2]

# 正确做法：用默认参数把当前值“冻结”
funcs2 = []
for i in range(3):
    funcs2.append(lambda i=i: i)

print([f() for f in funcs2])  # [0, 1, 2]
```

**关键结论**：闭包捕获的是**变量引用**（late binding，延迟绑定）。要立刻定格当前值，用**默认参数**。

---

## 第 4 节：lambda 的边界——什么时候不要用

lambda 不是万能的。工程中要遵守几条硬规则：

1. **不要用 `lambda` 给函数命名**（PEP 8）：

```python
# 错误：丧失了 lambda 的唯一优势，且函数名显示为 <lambda>
f = lambda x: 2 * x

# 正确：用 def
def f(x):
    return 2 * x
```

2. **lambda 体内不能写语句**（`if` 语句、`try`、`for` 循环都不行）。可以写**条件表达式**，但复杂了就难读：

```python
# 可以，但可读性差
f = lambda x: x * 2 if x > 0 else 0

# 更工程化的写法
def f(x):
    return x * 2 if x > 0 else 0
```

3. **lambda 没有类型注解（annotation）**。大型项目中用 `def` 配合 PEP 484 注解更清晰。

**关键结论**：lambda 适合“用一次、就一行、就地传入”。超过一行、需要命名、需要复用——一律用 `def`。

---

## 第 5 节：lambda 在工程级代码中的正确位置

工程级代码中，lambda 通常只出现在下面这几类“回调式”位置：

```python
# 1. sorted 的 key
users = [{'name': 'Al', 'age': 22}, {'name': 'Bo', 'age': 19}]
by_age = sorted(users, key=lambda u: u['age'])

# 2. 默认字典/回调
def on_error(msg):
    print('ERR:', msg)

handlers = {'error': on_error}
handlers.get('error', lambda m: print('ignore:', m))('boom')

# 3. 简单映射
cache = {}
get_len = lambda s: cache.setdefault(s, len(s))
```

但不推荐的做法包括：

- 把 lambda 赋给变量去复用（用 `def`）。
- 在 lambda 里写多分支逻辑（用 `def`）。
- 用 lambda 代替 `operator.itemgetter` / `operator.attrgetter`（性能更差、可读性也不一定更好）：

```python
from operator import itemgetter

users = [{'name': 'Al', 'age': 22}, {'name': 'Bo', 'age': 19}]
# 好：sorted(users, key=itemgetter('age'))
# 一般：sorted(users, key=lambda u: u['age'])
```

**关键结论**：工程里 lambda 只做“小、临时、就地”的回调；凡是可命名、可复用、可测试的逻辑，一律升级为 `def`。

## py.func.higher_order

# 高阶函数（Higher-Order Function）

> **一句话直觉**：函数不仅可以被调用，还可以像数字、字符串一样被当作“数据”传来传去。高阶函数就是“接收函数作为参数”或“把函数作为返回值”的函数。它是 Python 抽象能力的第一块基石，也是之后学装饰器、`map/filter/reduce`、PyTorch 的 `DataLoader(collate_fn=...)`、`Optimizer` 回调等一切工程技巧的地基。

---

## 1. 函数是“一等公民”（First-Class Citizen）

在很多语言里，函数只是“定义好就被固定”的代码块。但在 Python 中，**函数是对象**：可以赋值给变量、放进列表、当参数传、当返回值返回。

```python
# 函数可以赋值给变量
def greet(name: str) -> str:
    return f"Hello, {name}"

say_hi = greet          # say_hi 现在指向同一个函数对象
print(say_hi("Alice"))  # Hello, Alice

# 函数可以放进容器
funcs = [greet, len, str.upper]
print(funcs[0]("Bob"))  # Hello, Bob

# 函数甚至可以有属性
greet.lang = "en"
print(greet.lang)       # en
```

只要理解了“函数名只是一个指向函数的变量”，后面所有高阶函数的写法都会顺理成章。

---

## 2. 把函数当参数：最经典的高阶函数

**定义**：如果一个函数 `f` 的参数里包含另一个函数 `g`，那么 `f` 就是高阶函数。

最常见的例子是 Python 内置的 `sorted`：它接收一个 `key` 函数，让调用者决定“按什么排序”。

```python
words = ["apple", "pie", "banana", "kiwi"]

# key 是一个函数：按字符串长度排序
print(sorted(words, key=len))
# ['pie', 'kiwi', 'apple', 'banana']

# 按最后一个字母排序
print(sorted(words, key=lambda w: w[-1]))
# ['banana', 'apple', 'pie', 'kiwi']
```

这里 `len` 和 `lambda w: w[-1]` 都是“函数对象”，被传进 `sorted`。`sorted` 不关心你按什么规则排，它只负责把参数 `key` 对每个元素调用一次——这就是高阶函数的核心思想：**把“变化的部分”抽出来交给调用者。**

我们再手写一个高阶函数，加深理解：

```python
def apply_twice(func, x):
    """把 func 连续应用两次"""
    return func(func(x))

def add_one(n: int) -> int:
    return n + 1

print(apply_twice(add_one, 10))  # 12
print(apply_twice(lambda s: s * 2, "ab"))  # abababab
```

---

## 3. 把函数当返回值：工厂函数的起点

高阶函数不仅能“吃”函数，还能“吐”函数。这种写法常用于“根据配置生成不同的行为”。

```python
def make_multiplier(factor: int):
    """返回一个新函数，它会把输入乘以 factor"""
    def multiplier(x: int) -> int:
        return x * factor
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30
```

注意：内层函数 `multiplier` “记住了”外层变量 `factor`，即使外层函数已经返回。这种机制叫**闭包（Closure）**，是高阶函数能把“配置”封装进新函数的关键。

---

## 4. 标准库里的三件套：`map` / `filter` / `functools.reduce`

这三个是最典型的“把函数当参数”的高阶函数。虽然现在很多场景可以用列表推导替代，但在函数式风格和流式处理里仍然常见。

```python
from functools import reduce

nums = [1, 2, 3, 4, 5]

# map：对每个元素施加一个函数
squares = list(map(lambda x: x * x, nums))
print(squares)  # [1, 4, 9, 16, 25]

# filter：保留让函数返回 True 的元素
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)  # [2, 4]

# reduce：从左到右累积
total = reduce(lambda acc, x: acc + x, nums, 0)
print(total)  # 15
```

**工程建议**：简单变换优先用列表推导（可读性更好）；当函数已经存在（如 `str.strip`、`int`）或流水线很长时，`map/filter` 更自然。

```python
# 列表推导 vs map：都正确，看场景
upper1 = [s.upper() for s in ["a", "b"]]
upper2 = list(map(str.upper, ["a", "b"]))
print(upper1, upper2)  # ['A', 'B'] ['A', 'B']
```

---

## 5. 类型提示（Type Hints）：让高阶函数也“可读”

高阶函数的参数是函数，类型怎么写？用 `Callable[[参数类型], 返回类型]`。

```python
from typing import Callable

def transform(items: list[int],
              func: Callable[[int], int]) -> list[int]:
    """对 items 中每个元素调用 func，返回新列表"""
    return [func(x) for x in items]

print(transform([1, 2, 3], lambda x: x * 10))  # [10, 20, 30]
```

说明：
- `Callable` 来自 `typing` 模块；
- `Callable[[int], int]` 表示“接收一个 int、返回一个 int 的函数”；
- 类型提示**不会在运行时强制检查**，但 IDE、mypy、pyright 等工具会用它抓 bug。工程级代码应当写类型提示。

复杂一点：函数可能接收多个参数、返回任意类型：

```python
from typing import Callable, Any

Reducer = Callable[[Any, Any], Any]  # 类型别名

def fold(xs: list, init: Any, op: Reducer) -> Any:
    acc = init
    for x in xs:
        acc = op(acc, x)
    return acc

print(fold([1, 2, 3, 4], 0, lambda a, b: a + b))  # 10
```

---

## 6. 工程视角：为什么大项目离不开高阶函数

在 PyTorch 这类框架里，高阶函数无处不在：

- `DataLoader(dataset, collate_fn=my_collate)`：把“如何拼 batch”这个策略作为函数传入；
- `optimizer.step()` 背后的 `param_groups` 里，可以挂 `lr_lambda`（按 epoch 调整学习率的函数）；
- `model.apply(fn)`：把 `fn` 递归地作用到每个子模块上（初始化权重、迁移设备等都依赖这个模式）。

```python
# 伪代码，展示风格：把“策略”作为函数传入
def run_epoch(model, loader, loss_fn, step_fn):
    for x, y in loader:
        loss = loss_fn(model(x), y)
        step_fn(loss)
```

只要策略可能变化，就把它做成参数——这就是高阶函数在工程里的价值。

## 动手练习

**任务**：实现一个小型“数据清洗管道”。

要求：
1. 编写一个高阶函数 `build_pipeline(*steps)`，它接收任意多个“单参数函数”，返回一个新函数；
2. 新函数接收一个字符串，依次把每个 step 作用上去，返回最终结果；
3. 用下面 3 个 step 组装管道并测试：
   - `strip_spaces`：去掉首尾空格；
   - `to_lower`：转成小写；
   - `remove_punct`：去掉英文标点 `.,!?`。

示例骨架：

```python
def build_pipeline(*steps):
    def pipeline(text: str) -> str:
        for step in steps:
            text = step(text)
        return text
    return pipeline

# TODO: 定义三个 step 函数，组装，并测试：
# clean("  Hello, World!!  ")  -> "hello world"
```

**进阶挑战**：给 `build_pipeline` 加上类型提示，并用 `functools.reduce` 重写内部循环。完成后，你就掌握了 Python 高阶函数的核心：**把函数当数据，把变化的部分参数化。**

```python
from functools import reduce
from typing import Callable


def build_pipeline(*steps: Callable[[str], str]) -> Callable[[str], str]:
    """把多个单参数函数串成一个管道，返回组合后的新函数"""
    def pipeline(text: str) -> str:
        return reduce(lambda acc, step: step(acc), steps, text)
    return pipeline


def strip_spaces(s: str) -> str:
    return s.strip()


def to_lower(s: str) -> str:
    return s.lower()


def remove_punct(s: str) -> str:
    for ch in ".,!?":
        s = s.replace(ch, "")
    return s


clean = build_pipeline(strip_spaces, to_lower, remove_punct)

print(clean("  Hello, World!!  "))   # hello world
print(clean("  PyTorch, Rocks!  "))  # pytorch rocks

# 额外：演示 key 作为高阶函数参数
print(sorted(["apple", "pie", "banana"], key=len))  # ['pie', 'apple', 'banana']
```
