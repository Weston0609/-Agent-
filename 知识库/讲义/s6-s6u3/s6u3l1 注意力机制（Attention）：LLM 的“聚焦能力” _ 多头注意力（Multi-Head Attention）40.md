## ai.llm.attention

# 注意力机制（Attention）：LLM 的“聚焦能力”

> 一句话直觉：注意力机制让模型在处理一个词时，动态决定该“看”输入序列里的哪些词，并给它们分配不同权重，从而用上下文理解当前词。

---

## 1. 为什么需要注意力：从“平均看”到“重点看”

零基础先记住一个场景：翻译句子 “The cat sat on the mat” 时，翻译 “cat” 最该关注的是 “The” 和 “sat”，而不是 “mat”。早期模型把整句压成一个固定向量（fixed-length vector），信息会被“平均掉”。注意力机制（Attention Mechanism）的核心是：**为每个位置生成一组权重，对输入做加权求和**，让模型自己学“该看哪里”。

最小形式叫点积注意力（Dot-Product Attention）：用查询（Query）和键（Key）算相似度，再用相似度加权值（Value）。

```python
import torch
import torch.nn.functional as F

# 3 个 token，每个 token 用 4 维向量表示
x = torch.randn(3, 4)

# 简化：Q、K、V 都来自 x
Q = K = V = x

# 相似度分数：Q 与 K 的点积，并缩放
scores = Q @ K.T / (4 ** 0.5)  # shape: (3, 3)

# softmax 把分数变成权重，每行和为 1
weights = F.softmax(scores, dim=-1)

# 加权求和得到每个位置的新表示
out = weights @ V
print(weights)
print(out)
```

**关键结论**：注意力输出是“值（Value）的加权平均”，权重来自“查询（Query）与键（Key）的相似度”。

---

## 2. 自注意力（Self-Attention）：序列自己看自己

当 Q、K、V 都来自同一个输入序列时，叫自注意力（Self-Attention）。它让每个词都能直接和句子中任意词交互，距离不再是障碍。

```python
import torch
import torch.nn as nn

# 一个 batch：2 条样本，每条 3 个 token，每个 token 4 维
x = torch.randn(2, 3, 4)

# 用线性层分别生成 Q、K、V
d_model = 4
Wq = nn.Linear(d_model, d_model)
Wk = nn.Linear(d_model, d_model)
Wv = nn.Linear(d_model, d_model)

Q, K, V = Wq(x), Wk(x), Wv(x)

# 缩放点积注意力
scores = Q @ K.transpose(-2, -1) / (d_model ** 0.5)
weights = torch.softmax(scores, dim=-1)
out = weights @ V
print(out.shape)  # torch.Size([2, 3, 4])
```

**关键结论**：自注意力让每个位置聚合全序列信息，且权重是数据驱动的、可学习的。

---

## 3. 多头注意力（Multi-Head Attention）：并行看多种关系

一个注意力头只能学一种“关注模式”。多头注意力（Multi-Head Attention）把维度切成多份，并行做多次注意力，再拼接。这样模型可以同时关注语法、指代、语义等不同关系。

```python
import torch
import torch.nn as nn

batch, seq_len, d_model, n_heads = 2, 5, 8, 2
x = torch.randn(batch, seq_len, d_model)

# 标准多头注意力实现
mha = nn.MultiheadAttention(embed_dim=d_model, num_heads=n_heads, batch_first=True)
out, attn_weights = mha(x, x, x)

print(out.shape)          # torch.Size([2, 5, 8])
print(attn_weights.shape) # torch.Size([2, 5, 5])
```

**关键结论**：多头注意力 = 多组 Q/K/V 并行 + 拼接 + 线性投影，是 Transformer 的基本积木。

---

## 4. 因果掩码（Causal Mask）：GPT 为什么不能“偷看未来”

LLM（Large Language Model，大语言模型）通常做下一词预测（next-token prediction），第 t 个位置只能看 1..t，不能看 t+1 之后。实现方式是在 softmax 前把未来位置的分数设成负无穷。

```python
import torch

seq_len = 4
scores = torch.randn(seq_len, seq_len)

# 上三角（不含对角线）设为 -inf
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1).bool()
scores = scores.masked_fill(mask, float('-inf'))

weights = torch.softmax(scores, dim=-1)
print(weights)
# 每行只在对角线及左侧有非零值，未来位置权重为 0
```

**关键结论**：因果掩码保证自回归（autoregressive）生成时信息不泄露，是 GPT 类模型的关键。

---

## 5. 复杂度与工程要点：为什么长上下文很贵

注意力计算量随序列长度 n 呈 O(n²) 增长。n=4096 时分数矩阵有约 1600 万个元素；n=128k 时是 160 亿级。工程上常用 FlashAttention、稀疏注意力、滑动窗口注意力等优化显存和速度。

```python
import torch
import torch.nn.functional as F

# 用 PyTorch 内置 scaled_dot_product_attention，通常会自动选高效内核
def attention(q, k, v, causal=False):
    return F.scaled_dot_product_attention(q, k, v, is_causal=causal)

q = torch.randn(1, 4, 8, 16)  # batch, heads, seq, dim
k = torch.randn(1, 4, 8, 16)
v = torch.randn(1, 4, 8, 16)
out = attention(q, k, v, causal=True)
print(out.shape)  # torch.Size([1, 4, 8, 16])
```

**关键结论**：注意力是 LLM 的核心算子，但长序列下的 O(n²) 是主要瓶颈，工程优化围绕它展开。

## ai.llm.multihead

# 多头注意力（Multi-Head Attention）40 分钟讲义

> 一句话直觉：**让模型像多个专家同时从不同角度审阅同一句话，再把意见汇总，比只听一个人的判断更准。**

---

## 0. 为什么需要它？

在 Transformer（变换器）里，注意力（Attention）机制让每个词去“看”句子中其他词。但只用一套注意力权重，模型只能学到一种“关注模式”。比如句子「小明把书给了小红，因为她喜欢读书」中，理解「她」指谁，需要同时关注：

- 语法主语（小明 / 小红）
- 语义角色（给书的人、收书的人）
- 性别线索（她 → 女性）

**多头注意力（Multi-Head Attention, MHA）** 就是并行运行多套注意力，每套叫一个“头”（head），各自学习不同的关注模式，最后拼接融合。

---

## 1. 从单头到多头：核心公式

单头注意力（Scaled Dot-Product Attention，缩放点积注意力）的公式是：

$$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中：

- **Q（Query，查询）**：当前词想“问什么”
- **K（Key，键）**：每个词能“提供什么线索”
- **V（Value，值）**：每个词真正的“内容”
- **$d_k$**：每个头的维度，除以 $\sqrt{d_k}$ 是为了防止点积过大导致 softmax 梯度消失

多头把模型维度 $d_{model}$ 切成 $h$ 份，每个头维度 $d_k=d_v=d_{model}/h$：

$$\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O$$

$$\text{head}_i=\text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

关键点：**不是简单重复 h 次，而是每个头有独立的可学习投影矩阵 $W_i^Q, W_i^K, W_i^V$，最后再用 $W^O$ 融合。**

---

## 2. 形状变化：工程实现的关键

假设批次大小（batch size）$B$，序列长度（sequence length）$L$，模型维度 $d_{model}$，头数 $h$，每头维度 $d_k=d_{model}/h$。

| 张量 | 形状 |
|---|---|
| 输入 X | (B, L, d_model) |
| Q/K/V 投影后 | (B, L, d_model) |
| reshape 成多头 | (B, h, L, d_k) |
| 注意力分数 | (B, h, L, L) |
| 每个头输出 | (B, h, L, d_k) |
| 拼接后 | (B, L, d_model) |

工程上最常见的 bug 就是 **reshape / transpose 顺序写错**，导致头之间信息串味。

---

## 3. 为什么要除以 h？

如果直接把 $d_{model}$ 拿去做单头注意力，点积结果的方差会随维度线性增长。多头把维度均分后，每个头在低维空间计算，**总计算量几乎不变，但表达能力更强**：

- 单头：$L \times d_{model}$ 的 QK 计算
- 多头：$h \times L \times d_k = L \times d_{model}$，一样

所以多头是“几乎免费”的表达力升级。

---

## 4. 多头学到了什么？（可解释性）

论文 *Attention Is All You Need* 可视化显示：

- 有的头关注**相邻词**（局部语法）
- 有的头关注**句首/句尾**（全局结构）
- 有的头做**指代消解**（她 → 小红）
- 有的头几乎无用（可在推理时裁剪，即 head pruning）

这说明多头不是冗余，而是**分工**。
