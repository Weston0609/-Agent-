## ai.nn.training_loop

# 训练循环：从零到工程级

## 一句话直觉

**训练循环（training loop）** 是让神经网络（neural network）从“随机胡猜”变成“会预测”的反复学习过程：每轮拿一批数据算预测、算误差、算梯度、更新参数，循环直到模型变好。

---

## 1. 为什么需要训练循环？

神经网络一开始的参数（parameter）是随机初始化的，所以它一开始的输出没有意义。训练循环就是把它变成一个“会学习”的系统。

训练循环通常包含 5 个核心动作：

1. **前向传播（forward pass）**：输入数据，得到预测。
2. **计算损失（loss）**：衡量预测和真实答案差多少。
3. **反向传播（backward pass）**：自动计算每个参数对损失的梯度（gradient）。
4. **参数更新（optimizer step）**：按梯度方向微调参数。
5. **清零梯度（zero grad）**：防止梯度累积。

```python
import torch
import torch.nn as nn

# 1. 定义一个极简模型：1 个输入 -> 1 个输出
model = nn.Linear(1, 1)

# 2. 损失函数：均方误差
criterion = nn.MSELoss()

# 3. 优化器：随机梯度下降
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# 4. 造一批训练数据：y = 2x + 1
x = torch.tensor([[1.0], [2.0], [3.0], [4.0]])
y = torch.tensor([[3.0], [5.0], [7.0], [9.0]])

# 5. 训练循环
for epoch in range(100):
    y_pred = model(x)              # 前向传播
    loss = criterion(y_pred, y)    # 计算损失

    optimizer.zero_grad()          # 清零旧梯度
    loss.backward()                # 反向传播，算梯度
    optimizer.step()               # 更新参数

    if (epoch + 1) % 10 == 0:
        print(f"epoch {epoch+1}, loss={loss.item():.4f}")
```

## 2. 一个完整训练循环的四个关键对象

工程里，训练循环不是只写一个 `for` 循环，而是由四类对象协作：

### 2.1 模型（model）
负责把输入变成输出。

```python
import torch
import torch.nn as nn

class TinyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 16),
            nn.ReLU(),
            nn.Linear(16, 1)
        )

    def forward(self, x):
        return self.net(x)

model = TinyNet()
print(model)
```

### 2.2 数据加载器（DataLoader）
负责把数据分批次（batch）喂给模型。

```python
from torch.utils.data import TensorDataset, DataLoader

x = torch.linspace(-3, 3, 200).unsqueeze(1)
y = 2 * x + 1 + 0.1 * torch.randn_like(x)

dataset = TensorDataset(x, y)
loader = DataLoader(dataset, batch_size=32, shuffle=True)

for batch_x, batch_y in loader:
    print(batch_x.shape, batch_y.shape)
    break
```

### 2.3 损失函数（loss function）
决定“什么叫做错”。回归常用 `MSELoss`，分类常用 `CrossEntropyLoss`。

### 2.4 优化器（optimizer）
决定“怎样根据梯度改参数”。常见有 `SGD`、`Adam`。

```python
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
```

## 3. 标准训练循环：从单步到 epoch

### 3.1 单步训练函数

工程代码通常会把“一个 batch 的训练”封装成函数。

```python
import torch
import torch.nn as nn

model = nn.Linear(1, 1)
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

def train_step(batch_x, batch_y):
    model.train()                  # 进入训练模式
    y_pred = model(batch_x)        # 前向传播
    loss = criterion(y_pred, batch_y)

    optimizer.zero_grad()          # 清空梯度
    loss.backward()                # 反向传播
    optimizer.step()               # 更新参数
    return loss.item()
```

### 3.2 一个 epoch 的训练

```python
from torch.utils.data import TensorDataset, DataLoader

x = torch.linspace(-3, 3, 200).unsqueeze(1)
y = 2 * x + 1 + 0.1 * torch.randn_like(x)

loader = DataLoader(TensorDataset(x, y), batch_size=32, shuffle=True)

def train_one_epoch(model, loader, criterion, optimizer):
    total_loss = 0.0
    for batch_x, batch_y in loader:
        loss = train_step(batch_x, batch_y)
        total_loss += loss
    return total_loss / len(loader)
```

### 3.3 多 epoch 训练

```python
for epoch in range(20):
    avg_loss = train_one_epoch(model, loader, criterion, optimizer)
    print(f"epoch {epoch+1:02d}, avg_loss={avg_loss:.4f}")
```

## 4. 工程级训练循环必须加的三件事

### 4.1 验证集（validation set）
训练时不能只看训练损失，否则容易过拟合（overfitting）。

```python
@torch.no_grad()
def evaluate(model, loader, criterion):
    model.eval()                   # 进入评估模式
    total_loss = 0.0
    for batch_x, batch_y in loader:
        y_pred = model(batch_x)
        loss = criterion(y_pred, batch_y)
        total_loss += loss.item()
    return total_loss / len(loader)
```

### 4.2 设备管理（device）
把模型和数据放到 GPU 或 CPU。

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
model = model.to(device)

for batch_x, batch_y in loader:
    batch_x = batch_x.to(device)
    batch_y = batch_y.to(device)
    break
```

### 4.3 保存最佳模型（checkpoint）

```python
best_val_loss = float("inf")

for epoch in range(20):
    train_loss = train_one_epoch(model, loader, criterion, optimizer)
    val_loss = evaluate(model, loader, criterion)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        torch.save(model.state_dict(), "best_model.pt")

    print(f"epoch {epoch+1:02d}, train={train_loss:.4f}, val={val_loss:.4f}")
```

## 5. 把训练循环写成工程模板

下面是一个更接近真实项目的训练循环结构：

```python
import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

# 1. 准备数据
x = torch.linspace(-3, 3, 400).unsqueeze(1)
y = 2 * x + 1 + 0.1 * torch.randn_like(x)

n_train = 320
train_loader = DataLoader(TensorDataset(x[:n_train], y[:n_train]), batch_size=32, shuffle=True)
val_loader = DataLoader(TensorDataset(x[n_train:], y[n_train:]), batch_size=32)

# 2. 模型、损失、优化器
device = "cuda" if torch.cuda.is_available() else "cpu"
model = nn.Sequential(nn.Linear(1, 16), nn.ReLU(), nn.Linear(16, 1)).to(device)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 3. 单步训练
def train_step(batch_x, batch_y):
    model.train()
    batch_x, batch_y = batch_x.to(device), batch_y.to(device)
    y_pred = model(batch_x)
    loss = criterion(y_pred, batch_y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()

# 4. 评估
@torch.no_grad()
def evaluate(loader):
    model.eval()
    total = 0.0
    for batch_x, batch_y in loader:
        batch_x, batch_y = batch_x.to(device), batch_y.to(device)
        total += criterion(model(batch_x), batch_y).item()
    return total / len(loader)

# 5. 训练循环
best_val = float("inf")
for epoch in range(50):
    train_loss = 0.0
    for batch_x, batch_y in train_loader:
        train_loss += train_step(batch_x, batch_y)
    train_loss /= len(train_loader)
    val_loss = evaluate(val_loader)

    if val_loss < best_val:
        best_val = val_loss
        torch.save(model.state_dict(), "best_model.pt")

    if (epoch + 1) % 5 == 0:
        print(f"epoch {epoch+1:02d}, train={train_loss:.4f}, val={val_loss:.4f}")
```

这个模板已经包含：数据分批、训练/评估切换、设备管理、验证、保存最佳模型。

## ai.nn.overfit_debug

## 一句话直觉

**过拟合（overfitting）** 就像学生死记硬背了练习册答案，考试一换题就崩；**调试（debug）过拟合**，就是学会判断模型“背题”还是“真懂”，并用手段让它真正学到规律。

---

## 1. 什么是过拟合？先看一个最小例子

**过拟合**：模型在训练集上表现很好，但在没见过的数据（验证集/测试集）上表现很差。

直觉：模型把训练数据里的“噪声”也当成了规律。

```python
# 用多项式拟合带噪声的正弦曲线，直观看到过拟合
import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

rng = np.random.RandomState(0)
X = np.sort(rng.rand(30, 1) * 6, axis=0)
y = np.sin(X).ravel() + rng.normal(0, 0.25, X.shape[0])

X_test = np.linspace(0, 6, 200)[:, None]
y_true = np.sin(X_test).ravel()

for degree, color in [(1, 'blue'), (3, 'green'), (15, 'red')]:
    model = make_pipeline(PolynomialFeatures(degree), LinearRegression())
    model.fit(X, y)
    y_pred = model.predict(X_test)
    plt.plot(X_test, y_true, 'k--', label='真实曲线')
    plt.plot(X_test, y_pred, color=color, label=f'degree={degree}')
    plt.scatter(X, y, s=15, c='gray')
    plt.legend(); plt.title('多项式次数与过拟合'); plt.show()
```

**结论**：degree=15 时训练点几乎全穿过，但曲线剧烈震荡——这就是过拟合。

---

## 2. 怎么判断过拟合？看训练/验证两条曲线

关键指标是 **训练损失（training loss）** 与 **验证损失（validation loss）** 的差距。

- 训练损失低、验证损失高 → 过拟合
- 两者都高 → 欠拟合（underfitting）
- 两者都低且接近 → 好模型

```python
# 手动划分训练/验证集，观察两条 loss 曲线
import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(0)
N = 200
X = torch.randn(N, 1)
y = 3 * X + 1 + 0.5 * torch.randn(N, 1)  # 线性关系 + 噪声

# 用小样本训练，更容易过拟合
X_train, y_train = X[:20], y[:20]
X_val, y_val = X[20:], y[20:]

train_loader = DataLoader(TensorDataset(X_train, y_train), batch_size=5, shuffle=True)

model = nn.Sequential(nn.Linear(1, 128), nn.ReLU(), nn.Linear(128, 1))
opt = torch.optim.Adam(model.parameters(), lr=1e-2)
loss_fn = nn.MSELoss()

for epoch in range(200):
    model.train()
    for xb, yb in train_loader:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); opt.step()
    model.eval()
    with torch.no_grad():
        train_loss = loss_fn(model(X_train), y_train).item()
        val_loss = loss_fn(model(X_val), y_val).item()
    if epoch % 40 == 0:
        print(f'epoch {epoch:3d} | train {train_loss:.3f} | val {val_loss:.3f}')
```

**结论**：训练损失一路下降，验证损失却先降后升，就说明已经进入过拟合区。

## 3. 常用“过拟合调试”手段

按优先级推荐：

1. **增加数据**或 **数据增强（data augmentation）**
2. **降低模型复杂度**（层数、参数量）
3. **正则化（regularization）**：L2 权重衰减
4. **Dropout**：训练时随机丢弃神经元
5. **早停（early stopping）**：验证损失不再下降就停止

```python
# 加入权重衰减 + Dropout + 早停，观察验证损失
model = nn.Sequential(
    nn.Linear(1, 128), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(128, 128), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(128, 1)
)
opt = torch.optim.Adam(model.parameters(), lr=1e-2, weight_decay=1e-3)

best_val, patience, wait = float('inf'), 20, 0
for epoch in range(300):
    model.train()
    for xb, yb in train_loader:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); opt.step()
    model.eval()
    with torch.no_grad():
        val_loss = loss_fn(model(X_val), y_val).item()
    if val_loss < best_val:
        best_val, wait = val_loss, 0
    else:
        wait += 1
        if wait >= patience:
            print(f'早停于 epoch {epoch}, best_val={best_val:.3f}')
            break
```

**结论**：正则化和早停能显著缩小训练—验证差距。

---

## 4. 系统化调试流程

遇到过拟合，按这个清单走：

1. **先画曲线**：train loss vs val loss 随 epoch 的变化
2. **确认划分正确**：验证集不能混入训练集（数据泄漏）
3. **逐步调整**：先加正则，再考虑降复杂度/加数据
4. **固定随机种子**，保证对比公平
5. **一次只改一个变量**，记录每次结果

```python
# 简单记录函数，方便对比不同配置的 train/val loss
def evaluate(model, X_tr, y_tr, X_va, y_va):
    model.eval()
    with torch.no_grad():
        tr = loss_fn(model(X_tr), y_tr).item()
        va = loss_fn(model(X_va), y_va).item()
    return {'train': round(tr, 3), 'val': round(va, 3), 'gap': round(va - tr, 3)}

print(evaluate(model, X_train, y_train, X_val, y_val))
```

**结论**：把“调参”变成“对照实验”，过拟合调试就不再靠运气。

**过拟合调试 = 用验证集当“照妖镜”，看清模型是在学规律还是在背答案；然后用数据、正则、简化、早停把它拉回正轨。**
