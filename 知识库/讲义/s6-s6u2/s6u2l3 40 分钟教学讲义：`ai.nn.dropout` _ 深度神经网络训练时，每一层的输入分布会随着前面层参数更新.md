## ai.nn.dropout

# 40 分钟教学讲义：`ai.nn.dropout`

## 一句话直觉
**Dropout（随机失活）是一种在训练神经网络时随机“关掉”一部分神经元的技术，用来防止模型死记硬背训练数据，从而提升在新数据上的表现。**

你可以把它想成：每次训练都让不同的学生（神经元）轮流发言，逼着每个人都能独立解决问题，而不是只靠某几个学霸撑场面。

---

## 1. 为什么需要 Dropout？

神经网络如果参数很多、训练数据很少，很容易 **过拟合（overfitting）**：在训练集上准确率很高，在测试集上却很差。

Dropout 的核心思想：
- 训练时，每一层（或指定层）的神经元以概率 `p` 被临时“丢弃”（输出置 0）。
- 被丢弃的神经元本次不参与前向传播和反向传播。
- 测试/推理时，所有神经元都参与，但输出会按比例缩放，保持期望一致。

这样模型不会过度依赖某个神经元，学到的特征更鲁棒（robust）。

---

## 2. Dropout 的数学直觉

假设某层输出为向量 `h`，Dropout 概率为 `p`（丢弃概率）：

训练阶段：
- 生成一个与 `h` 同形状的伯努利掩码（mask）`m`，每个元素以概率 `1-p` 为 1，以概率 `p` 为 0。
- 输出为 `h * m`。
- 为了保持训练和测试的期望一致，通常对结果除以 `1-p`，这叫 **inverted dropout（反向 Dropout）**。

测试阶段：
- 不做任何丢弃，也不缩放，直接输出 `h`。

一句话：**训练时随机丢弃并放大保留的神经元，测试时全部使用。**

---

## 3. PyTorch 中的 `nn.Dropout`

在 PyTorch 中，`torch.nn.Dropout` 是一个层（module），用法非常简单：

```python
import torch
import torch.nn as nn

dropout = nn.Dropout(p=0.5)  # p 是丢弃概率，默认 0.5
x = torch.ones(4, 4)         # 4x4 全 1 输入

dropout.train()              # 训练模式：随机丢弃
y_train = dropout(x)
print("训练模式输出：")
print(y_train)

dropout.eval()               # 评估模式：不丢弃
print("评估模式输出：")
print(dropout(x))
```

关键点：
- `p` 是 **丢弃概率**，不是保留概率。
- 必须正确切换 `train()` 和 `eval()` 模式，否则推理结果会不稳定。
- `nn.Dropout` 默认使用 inverted dropout，测试时不需要手动缩放。

---

## 4. 在神经网络中怎么放 Dropout？

常见做法：
- 在全连接层（Linear）之后、激活函数之后，或者激活函数之前。
- 卷积层（Conv）之后也可以加，但更常用 `nn.Dropout2d`。
- 输入层也可以加较小的 dropout，但现代网络更常放在中间层。

示例：

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 256),
            nn.ReLU(),
            nn.Dropout(p=0.5),      # 隐藏层后丢弃一半
            nn.Linear(256, 10)
        )

    def forward(self, x):
        return self.net(x)

model = MLP()
model.train()
print(model(torch.randn(8, 784)).shape)  # torch.Size([8, 10])
model.eval()
print(model(torch.randn(8, 784)).shape)
```

---

## 5. 训练与评估的差异

非常重要：
- **训练时**：Dropout 随机丢弃，输出有随机性。
- **评估/推理时**：Dropout 不丢弃，输出确定。

如果你忘记调用 `model.eval()`，推理结果会带随机性，指标会变差。

典型训练循环：

```python
model.train()
for x, y in train_loader:
    optimizer.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()
    optimizer.step()

model.eval()
with torch.no_grad():
    for x, y in test_loader:
        pred = model(x)
        # 计算准确率等
```

---

## 6. 常用超参数与建议

- `p=0.5` 是经典默认值，适合全连接隐藏层。
- 输入层常用 `p=0.1~0.2`。
- 卷积层常用 `p=0.1~0.3`。
- 如果模型欠拟合（underfitting），减小 `p` 或去掉 Dropout。
- Dropout 常与权重衰减（weight decay）、批归一化（BatchNorm）等正则化手段配合。

注意：BatchNorm 和 Dropout 同时使用时，顺序和位置要谨慎，通常 Dropout 放在 BatchNorm 之后。

## 8. 常见误区提醒

- 把 `p` 当成保留概率：`p=0.5` 表示丢弃 50%，保留 50%。
- 推理时忘记 `eval()`：结果随机，评估不稳定。
- 训练时忘记 `train()`：Dropout 不生效，正则化失效。
- 在小模型上盲目加高 Dropout：可能导致欠拟合。
- 以为 Dropout 能替代所有正则化：它只是工具之一。

---

## 9. 小结

- Dropout 是训练时随机丢弃神经元、测试时全量使用的正则化方法。
- PyTorch 用 `nn.Dropout(p)` 实现，注意 `train()` / `eval()` 切换。
- 它通过打破神经元之间的共适应（co-adaptation）来提升泛化能力。
- 合理选择 `p`，并与其他正则化手段配合使用。

## ai.nn.batchnorm

## 一句话直觉
**BatchNorm（批量归一化，Batch Normalization）** 就像给神经网络每一层的输入做一次“标准化体检”，让数据分布更稳定，从而训练更快、更不容易跑偏。

---

## 1. 为什么需要 BatchNorm？

深度神经网络训练时，每一层的输入分布会随着前面层参数更新而不断变化，这被称为 **内部协变量偏移（Internal Covariate Shift）**。它会导致：
- 学习率不能设太大
- 需要精细初始化
- 容易陷入饱和区（如 Sigmoid 两端）

BatchNorm 的核心思想：对每个 mini-batch（小批量）的数据，按特征维度做归一化，使其均值接近 0、方差接近 1，然后再用两个可学习参数缩放和平移。

公式：

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$

$$y = \gamma \hat{x} + \beta$$

其中 $\mu_B$、$\sigma_B^2$ 是当前 batch 的均值和方差，$\gamma$、$\beta$ 是可学习参数。

```python
import torch
import torch.nn as nn

# 一个简单的 BatchNorm1d 示例
bn = nn.BatchNorm1d(num_features=3)
x = torch.randn(4, 3)  # batch_size=4, 特征数=3
y = bn(x)
print(y)
```

---

## 2. 训练与推理阶段的区别

- **训练阶段**：使用当前 mini-batch 的均值和方差进行归一化，同时用滑动平均更新全局均值和方差。
- **推理阶段**：使用训练阶段累计的全局均值和方差，不再依赖当前 batch。

这也是为什么模型在 `train()` 和 `eval()` 模式下 BatchNorm 行为不同。

```python
model = nn.Sequential(
    nn.Linear(3, 5),
    nn.BatchNorm1d(5)
)

model.train()  # 训练模式：使用 batch 统计量
out_train = model(torch.randn(4, 3))

model.eval()   # 推理模式：使用 running_mean / running_var
out_eval = model(torch.randn(4, 3))
print(out_train.shape, out_eval.shape)
```

---

## 3. 在 CNN 中怎么用？

对于卷积层，BatchNorm 通常作用在通道维度上，使用 `nn.BatchNorm2d`。

```python
import torch.nn as nn

conv_bn = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),
    nn.BatchNorm2d(16),
    nn.ReLU()
)

x = torch.randn(2, 3, 8, 8)  # N=2, C=3, H=8, W=8
y = conv_bn(x)
print(y.shape)  # torch.Size([2, 16, 8, 8])
```

## 4. 手动实现一个简化版 BatchNorm

理解内部机制最好的方式是自己写一遍。

```python
import torch

def manual_batchnorm(x, gamma, beta, eps=1e-5):
    # x: [N, C]，按特征维度 C 做归一化
    mean = x.mean(dim=0, keepdim=True)
    var = x.var(dim=0, unbiased=False, keepdim=True)
    x_hat = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_hat + beta

x = torch.randn(4, 3)
gamma = torch.ones(3)
beta = torch.zeros(3)
out = manual_batchnorm(x, gamma, beta)
print(out.mean(dim=0), out.std(dim=0, unbiased=False))
```

## 5. 工程实践要点

- **batch size 太小**：统计量不稳定，效果变差，可考虑 GroupNorm 或 LayerNorm。
- **位置**：通常放在线性/卷积层之后、激活函数之前。
- **推理导出**：部署时务必切换到 `eval()`，否则结果会随 batch 变化。
- **与 Dropout 配合**：顺序通常是 `Linear -> BatchNorm -> ReLU -> Dropout`。

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(10, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, 1)
        )
    def forward(self, x):
        return self.net(x)

model = MLP()
model.train()
out = model(torch.randn(8, 10))
print(out.shape)
```
